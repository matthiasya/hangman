# hangman

My own version of hangman — the classic word-guessing game.

## How to play

1. A secret word is chosen and shown as a row of blanks.
2. Guess one letter at a time.
3. Correct guesses reveal every matching letter in the word.
4. Wrong guesses add a piece to the hangman drawing.
5. Win by revealing the whole word before the drawing is complete.
